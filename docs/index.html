profileforge

Generate a beautiful GitHub profile README + dev card in one command.

Download View on GitHub

Install

go install github.com/v01dst/profileforge@latest

Use

profileforge v01dst -theme dark -out ./profile

Produces README.md and card.svg. Drop the README into a repo named after your username.

Features

📊 Stats

repos, stars, followers, forks, account age

🗣️ Languages

computed from your actual repos

🌟 Projects

auto-selected by stars

🎨 Themes

dark & light

🖼️ SVG card

embed anywhere

🪶 Zero deps

Go stdlib only
